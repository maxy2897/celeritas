# Instrucciones para Claude

Antes de trabajar en Celeritas, lee `COLLABORATION.md` y revisa el estado del repositorio.

Trabaja únicamente sobre esta carpeta. Puedes modificar cualquier archivo, página, contenido, estilo, comportamiento o funcionalidad cuando el usuario te lo pida. Las instrucciones actuales y explícitas del usuario tienen prioridad sobre restricciones de diseño anteriores.

Puedes crear o eliminar páginas, vehículos, formularios, filtros, enlaces, animaciones y funcionalidades si forman parte de la petición del usuario. Conserva únicamente el trabajo no relacionado con la solicitud y no sobrescribas cambios ajenos accidentalmente.

También puedes publicar la web cuando el usuario te lo pida. La publicación oficial se realiza en el repositorio `https://github.com/maxy2897/celeritas` mediante GitHub Pages. No uses el antiguo alojamiento de ChatGPT/OpenAI Sites.

Antes de editar, revisa `git status`. Cuando termines, ejecuta `npm run build`, indica qué archivos cambiaste y confirma si la publicación se completó correctamente.
