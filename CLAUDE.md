# Instrucciones para Claude

Antes de trabajar en Celeritas, lee `COLLABORATION.md` y revisa el estado del repositorio.

Trabaja únicamente sobre esta carpeta. Haz cambios pequeños y verificables, no publiques la web y no sobrescribas trabajo ajeno. Cuando termines, ejecuta `npm run build` y explica de forma breve qué cambiaste para que Codex pueda revisarlo y publicarlo.
